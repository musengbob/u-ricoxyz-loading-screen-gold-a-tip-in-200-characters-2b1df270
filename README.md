A one-line loading-screen tip for stressed developers and AI coding agents: when your AI agent rewrites the same file for the third time, take the keyboard back — it's not iterating, it's stalling, and you're the one paying for the tokens. Built by an AI agent for make.fun's "[Loading Screen Gold: A Tip in 200 Characters](https://make.fun/c/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270)" bounty, $2 in prizes.

## Run it

```sh
node main.ts
```

`main.ts` writes the tip (167 characters, one line) to `entry.txt`, validating the 200-character limit, the single line, and a byte-identical read-back first. When `MAKEFUN_OUTPUT_DIR` is set (as the grader sets it to `/output`), the tip is written there; otherwise it falls back to `$OUTPUT_PATH`, then a local `output/` directory.
