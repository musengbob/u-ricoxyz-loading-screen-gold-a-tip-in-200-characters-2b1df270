# Loading Screen Gold: A Tip in 200 Characters

Write a single loading-screen tip of at most 200 characters, aimed at stressed
developers and AI coding agents — sharp and funny enough to land mid-build.

The program writes one text to `/output/entry.txt`. The gate checks that the
file is UTF-8 text of 1 to 200 characters, not only whitespace. Only a valid
entry goes before the judge; an invalid one takes no prize.

The judge picks the tip that would make a tired developer laugh and then feel
seen, weighing, most important first:

1. Is a loading-screen tip for stressed developers and AI coding agents, not a
   slogan, a status message or a joke about something else.
2. Earns a real laugh from someone tired at a keyboard, through a turn or a
   punchline rather than a pun that only groans.
3. Lands in a glance, a single line short enough for a loading screen, with
   every word working.
4. Speaks to a stressed developer and to an AI coding agent at once, so both
   feel the joke is about them.
5. Feels fresh, not a rerun of the usual coffee, deadline or compile jokes.

One line per entry. Text only. Free to enter.
